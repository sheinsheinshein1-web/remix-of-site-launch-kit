# Пакет для редизайна страницы «Платформа»

## Как использовать

1. Загрузите в выбранную ИИ файл `PROMPT.md`.
2. Вместе с ним приложите `current-desktop.png` и `current-mobile.png` как референсы текущего состояния.
3. Напишите короткое сообщение: «Выполни задание из PROMPT.md и верни один готовый файл index.html».
4. Скачайте полученный от ИИ `index.html` и откройте его двойным кликом в браузере.

Если сервис не принимает файлы, откройте `PROMPT.md`, скопируйте текст между маркерами «НАЧАЛО ПРОМПТА» и «КОНЕЦ ПРОМПТА» и вставьте его в чат. Затем добавьте два скриншота.

## Что должно получиться

Один самодостаточный адаптивный HTML-прототип с рабочими вкладками, раскрытиями, локальной навигацией, галереей и светлой/тёмной темой. Этот HTML будет вариантом нового дизайна для обсуждения, а не автоматической заменой действующей страницы.
